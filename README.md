# How to fetch the sources
For making the sources work, you need to download the branch archive I made and rename it to `jimedrand-4.3.1-pure-man-sources.vroid` with these commands below
```sh
wget -c -o jimedrand-4.3.1-pure-man-sources.vroid https://github.com/jimed-rand/jim-vroid-model-source/archive/refs/heads/4.3.1-pure-man.zip
```
